Rust · PYNQ-Z2
学习目标 资源 交叉编译速查

自定进度 · 每课约 2–3 小时

从嵌入式 C 到 Rust 用户态程序

先从 TF 卡启动官方 PYNQ-Z2 镜像，再在 Debian 13 AMD64 主机上开发和交叉编译；从小型 SPI、UART 模块走到 TCP 数据传输，Debian 13 迁移留到后续评估。

课程路径

先建立 Rust 语言基础，再把同一套所有权和错误处理方法用于 Linux 外设与网络 I/O。每课都有一项可检查的成果。

设备与构建边界

Rust 程序运行在 PYNQ-Z2 的 Linux 用户态，复用现有设备树、驱动和设备节点。主课程不编写内核驱动、裸机固件或 FPGA RTL。TCP 使用 Linux 提供的 socket。

外设访问会先使用 Rust 用户态库；课程会说明库与 Linux 设备接口的对应关系。真实 C 源码会等到实际迁移阶段再收集。

课程资料以一课一页的方式累积。完成任务后，把运行结果或遇到的错误带回课程对话。
