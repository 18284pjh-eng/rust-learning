AMD64 → ARM Linux

Rust 编译器产生目标架构代码；目标 C 工具链负责链接 Linux 程序所需的原生部分。PYNQ-Z2 默认使用 ARMv7 hard-float。

最小步骤

sudo apt install gcc-arm-linux-gnueabihf
rustup target add armv7-unknown-linux-gnueabihf
cargo build --release --target armv7-unknown-linux-gnueabihf

如果 Cargo 找不到目标链接器，在项目的 .cargo/config.toml 中指定：

[target.armv7-unknown-linux-gnueabihf]
linker = "arm-linux-gnueabihf-gcc"

检查结果

file target/armv7-unknown-linux-gnueabihf/release/target-probe
readelf -h target/armv7-unknown-linux-gnueabihf/release/target-probe

检查输出是否为 ELF 32 位、ARM EABI5、hard-float。之后把可执行文件复制到板上运行；板上程序的目标架构应报告 armv7l。

记住

  • rustup target add 安装 Rust 对应目标的标准库，不会安装 GNU 链接器。
  • --target 设定程序的目标平台；本机直接 cargo run 仍运行 AMD64 版本。
  • 交叉编译成功证明产物格式正确；最终仍要在 PYNQ-Z2 上运行验收。

主要资料：rustup 交叉编译指南、Cargo 配置参考。
