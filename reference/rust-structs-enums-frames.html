结构体、枚举与数据帧

用结构体命名相关字段，用枚举限制有限状态，用 match 让编译器检查状态处理是否完整。

结构体：把字段放在一起

#[derive(Debug, Clone, Copy)]
struct UartConfig {
    baud: u32,
    data_bits: u8,
    stop_bits: u8,
    parity: Parity,
}

let config = UartConfig {
    baud: 115_200,
    data_bits: 8,
    stop_bits: 1,
    parity: Parity::None,
};

使用点号访问字段：config.baud。字段名比元组位置表达得更清楚。

枚举：一个值的有限变体

enum Parity {
    None,
    Even,
    Odd,
}

enum Frame {
    Data { sequence: u16, payload: [u8; 4] },
    Error { code: u8 },
}

枚举变体可以没有数据，也可以携带不同字段。使用全名构造：Parity::Even、Frame::Error { code: 2 }。

match：按状态读取数据

fn frame_summary(frame: &Frame) -> (&'static str, usize) {
    match frame {
        Frame::Data { payload, .. } => ("data", payload.len()),
        Frame::Error { .. } => ("error", 0),
    }
}
  • 每个 arm 使用 pattern => expression。
  • .. 忽略当前不需要的字段。
  • 枚举的所有变体必须被覆盖；否则编译器报 non-exhaustive patterns。
  • 使用 &Frame 只借用读取，避免函数拿走帧的所有权。

UART 帧标签

fn frame_label(config: &UartConfig) -> &'static str {
    match (config.data_bits, config.parity, config.stop_bits) {
        (8, Parity::None, 1) => "8N1",
        (8, Parity::Even, 1) => "8E1",
        (8, Parity::Odd, 1) => "8O1",
        _ => "custom",
    }
}

这里匹配的是一个三元组，返回值都是字符串字面量，因此返回类型可以是 &'static str。
