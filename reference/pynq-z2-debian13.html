Reference · Board bring-up

PYNQ-Z2 Debian 13

保留 Zynq-7000 板级启动链，用 Debian 13 armhf 根文件系统替换用户空间。

架构结论

  • PYNQ-Z2：Zynq Z7020，双核 Cortex-A9，32 位 ARMv7。
  • Debian 13 用户空间：armhf。
  • Rust 常用目标：armv7-unknown-linux-gnueabihf。
  • 板级启动文件：FSBL/BOOT.BIN、U-Boot、Linux kernel、DTB；具体文件名由镜像版本决定。

主机准备

sudo apt update
sudo apt install debootstrap qemu-user-static binfmt-support rsync \
  parted dosfstools e2fsprogs
mkdir -p ~/pynq-z2-debian/rootfs
sudo debootstrap --arch=armhf --foreign trixie \
  ~/pynq-z2-debian/rootfs http://deb.debian.org/debian
sudo cp /usr/bin/qemu-arm-static ~/pynq-z2-debian/rootfs/usr/bin/
sudo chroot ~/pynq-z2-debian/rootfs /debootstrap/debootstrap --second-stage

TF 卡原则

  1. 用 lsblk 确认整卡设备，再写入官方 PYNQ-Z2 镜像。
  2. 先启动官方镜像并保存串口日志、启动分区、BOOT.BIN、内核和 DTB。
  3. 只替换已确认的 ext4 根分区；不要覆盖板级启动分区。
  4. 让 U-Boot 的 root= 指向新根分区的标签或 PARTUUID。
  5. 首次启动只通过串口验收；网络、SSH、SPI/UART 设备节点随后逐项验证。

验收命令

cat /etc/os-release
uname -a
uname -m
dpkg --print-architecture
cat /proc/device-tree/model
cat /proc/consoles
systemctl --failed
ls -l /dev/ttyPS* /dev/spidev* 2>/dev/null

预期重点：Debian 13、armv7l、armhf。若出现 aarch64，先暂停并核对板卡与系统来源。
