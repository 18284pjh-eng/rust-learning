表达式、类型与控制流

用最少的语法构造可检查的配置逻辑，为所有权、错误处理和 Linux I/O 做准备。

绑定与类型

let baud: u32 = 115_200;
let data_bits: u8 = 8;
let mut attempts = 0;
attempts += 1;

let label = "8N1";       // &str
let ready = true;        // bool
  • let 默认不可变；只有需要修改绑定时才用 let mut。
  • 类型在编译期确定；数字类型和字符串切片不会自动互换。
  • 同一作用域可以重新绑定同名变量，这叫 shadowing；它和修改原绑定不同。

表达式与函数

fn classify_baud(baud: u32) -> &'static str {
    if baud <= 9_600 {
        "slow"
    } else if baud <= 115_200 {
        "normal"
    } else {
        "fast"
    }
}

函数签名写清输入和输出。代码块最后一个表达式可以成为返回值；如果写分号，它就变成语句。

条件与循环

let frame = if data_bits == 8 && parity == "N" && stop_bits == 1 {
    "8N1"
} else {
    "custom"
};

for baud in [9_600, 19_200, 115_200] {
    println!("{baud}: {}", classify_baud(baud));
}

if 每个分支必须产生兼容类型。for 适合遍历固定的候选配置；后续处理设备输入时，再把错误显式建模为 Result。

构建命令

cargo fmt
cargo check
cargo build --release
cargo run --target x86_64-unknown-linux-gnu

项目的 .cargo/config.toml 可以把 ARMv7 设为默认目标；最后一条命令临时覆盖它，让程序在 AMD64 主机上运行。
